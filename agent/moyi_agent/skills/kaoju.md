# 考据引用与证据分层 —— 如何诚实地引用本馆语料

## 何时用
任何需要引诗证事、报数字、下结论的场合。此为全局规范，其余技艺皆以此为底。

## 铁律
1. **不背诵，必检索**。引用任何诗句前，先以 `search_full_text` 或 `get_work` 取语料
   原文，逐字照录；记忆中的文本可能与语料版本异文，以语料为准并可注明「本馆藏本作某」。
2. **每个数字有出处**。「杜鹃在清代 475 见」这类数须来自工具返回值，并注明口径
   （档案层/广谱层；见 yixiang 技艺）。
3. **知之为知之**。广韵无考之字如实报无考；指纹库未收之作者如实说未收；
   典故表仅 28 目人工复核层，未收不等于非典。

## 证据分层（语料建库口径，向用户交代来源等级）
- **A 权威层**：唐诗三百首、宋词三百首等定评选本；龙榆生词谱。
- **B 大库层**：全唐诗、全宋诗（抽样）、御定历代赋汇等大型总集。
- **C 补遗层**：明清补遗（自 Werneror/Poetry 等分层抽样，扉页有说明）。
- 层级不同，说服力不同：孤证出 C 层者措辞宜留余地。

## 版本与繁简
- 语料检索统一繁→简折叠；向用户呈现时依语料原貌（多为繁体或原书用字）。
- 同题异文、一句多主（如名句被多家化用）常见——`famous_line_check` 的 earliest
  是「今存所见最早」，不是「原创者判定」。

## 应答体例
- 先结论后证据；证据给「《题》作者·朝代（work id）：原句」。
- 统计叙述给分母（如「共现 668 篇，占含剑之篇 x%」需两个数都可溯源时才说占比）。
- 用户若要遍览，转介 works_by_tag / search 系工具的分页（limit 参数），勿伪称穷尽。

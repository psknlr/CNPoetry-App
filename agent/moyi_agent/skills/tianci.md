# 依谱填词 —— 龙榆生《唐宋词格律》工作流程

## 何时用
用户要填词（给定或待选词牌），或问某词是否合某调之谱。

## 流程
1. **择调**：`list_cipai(关键词)` 检词牌（含别名）；题材与声情相配——
   豪放宜《念奴娇》《满江红》《贺新郎》，婉约宜《浣溪沙》《蝶恋花》《卜算子》，
   《雨霖铃》凄切、《破阵子》雄健。category 字段标平韵格/仄韵格/平仄韵转换格等。
2. **读谱**：`cipai_pattern(词牌)` 取谱面。符号：○平 ●仄 ⊙可平可仄 △平韵 ▲仄韵。
   **△▲ 是韵标，缀于韵脚字之后、本身不占字位**（如浣溪沙谱 47 符号实为 42 字 + 5 韵标），
   且韵标收紧该位平仄：△必平、▲必仄，即便原作 ⊙。一调多体时以 all_forms 列体式供选。
3. **起韵**：`suggest_slot(词牌, 谱位序号)` 于韵位未填时列可选韵部；已填部分词句后
   传 filled_text，工具按已押韵位推定韵部、给同韵常用字（按语料频次排序）。
4. **填写**：逐句填入。词之用韵以《词林正韵》十九部为通行口径（数部平水韵合用）；
   平水异部而词林同部者，填词不为出韵。
5. **校验**：`check_ci(词牌, 词稿)` 逐字对谱位判平仄，检韵位归部一致性
   （先平水，不齐退词林）、缺字多字、撞句与名句。cells 只列不合各位，改之。
6. **复核**：改后必再跑 `check_ci`；合谱后可以 `famous_line_check` 核警句。

## 判定口径
- 领格字（！仄领 ～平领）、豆（、）、对偶｛｝、叠韵［］、可省（）等标注不占字位。
- 填词多用成句本属常法（集句词自古有之），惟须自知所本——撞句提示给出原出处，
  转告用户即可，不必强令避改。

## 例
「用卜算子写梅」→ list_cipai 确认 → cipai_pattern 得 44 字仄韵格 → suggest_slot
起仄韵（如第四部纸/尾）→ 成稿 → check_ci → 出律 2 处改定 → 复核通过。

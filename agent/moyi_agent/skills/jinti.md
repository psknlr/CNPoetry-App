# 近体诗创作与校验 —— 从谱式到成篇的工作流程

## 何时用
用户要写/改/评五绝、七绝、五律、七律，或问「这首诗合律吗」。

## 流程
1. **定式**：问明（或从内容推定）五言/七言、绝/律、拟押之韵。不必逐字背谱——
   校验工具内置四起式标准谱。
2. **选韵**：以 `rhyme_group()` 列平水韵部，或 `char_rhyme(字)` 反查拟用韵脚之归部。
   宽窄参考：东、支、先、阳、庚、尤为宽韵；江、佳、肴、咸为窄韵。
3. **起草**：草稿每行一句。严格位为二四六与句脚（五言二四与句脚），一三五通常不论；
   联内须对（二四六平仄相反），联间须粘（后联出句二字平仄同前联对句）。
4. **校验**：`check_jinti(text)` 一次给出——最近谱式与出律位、粘对之失、拗救识别
   （孤平救／特拗四拗三救／半拗对句救三式，识出者不作出律论）、三平尾三仄尾、
   韵脚平水归部、与古人撞句、是否含历代名句。
5. **修改**：逐条回应校验结果。出律处优先动一三五闲字腾挪；孤平（B 式「平平仄仄平」
   首字用仄）必救——第三字改平。改后**必须再跑一次 check_jinti 复核**，不可凭感觉宣布合律。
6. **撞句处置**：撞名句非病，化用得当自成新意，但须向用户指明来历（famous 字段给出
   最早出处与历代化用家数）；撞僻句宜改，勿掠美。

## 判定口径（对用户如实交代）
- 逐字依《广韵》，两读（「两」）与无考字按通配，不妄判。
- 拗救仅识三式，其余变格不穷尽；「出律 0 处」意为初筛无失，非等于绝对合律。
- 首句入韵与否影响谱式判定；工具已按韵脚自动加权。

## 例
用户草稿四句七言 → `check_jinti` → 报「平起入韵，出律 1 处（第三句第六字），失粘一处」
→ 建议改字 → 复核 → 通过后再以 `famous_line_check` 核警句原创性。

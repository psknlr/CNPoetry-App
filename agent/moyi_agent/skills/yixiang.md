# 意象经营与溯源 —— 从单象到搭配的分析流程

## 何时用
用户问某意象之情感/季节/时代脉络，要为创作择象，或要考某搭配（如「剑·酒」）的来历。

## 两层口径（必须分清、如实交代）
- **档案层**（50 目）：严格例证口径，每条情感关联都有 poem_id + 原句可核。
- **广谱层**（207 目 / 715 表层词形）：表层词形匹配口径，覆盖 97% 作品。
- 两层计数不同源（如杜鹃元代档案层 22、广谱层 76），引用数字时注明口径。

## 工具用法
1. 单象全貌：`imagery_profile(名)` → 表层词形、情感关联（带例证原句）、共现意象、
   朝代分布、四时偏好（season_rates_pct）、头部搭配及其首用时代。
2. 取例证：`works_by_tag("imagery", 名)` 严格层；`works_by_tag("wide", 名)` 广谱层；
   可加朝代参数。逐篇 `get_work(id)` 引原文。
3. 搭配考察：`co_occurrence(甲, 乙)` → 共现篇目 + 分代每万篇共现率（rates 为率非绝对数，
   跨代可比）+ 何代为峰 + 最早时代与早期高频作者。
   **慎言「首创」**：first_who 是「现存语料中最早时代的高频使用者」，语料有存佚之偏，
   只可说「今存所见最早」，不可断为发明人。
4. 季节择象：用户明言季节时，imagery_profile 的 season_rates_pct 可荐当季常用之象；
   同时说明**反季取象自古有之**（「人间四月芳菲尽，山寺桃花始盛开」），此为采择之资
   非规矩之绳。
5. 典故意象：涉「阳关」「折柳」「南浦」之类，先 `allusion_lookup(词)` 取出处与寓意
   （此表为人工复核层，仅 28 目，未收不等于非典）。

## 叙述规范
- 每个统计论断落到可点验的证据：给 work id 与原句，用户可查。
- 情感关联的 support 分「显证/邻证」，显证为情感词与意象同句，邻证为邻句——
  引用时优先显证例。

# 选韵与检韵 —— 平水韵·词林正韵双口径

## 何时用
用户问某字押什么韵、某组字是否同韵、写作时选哪个韵部，或问平水/词林之别。

## 口径先明
- **近体诗以平水韵 106 部为绳**：一韵到底，不得出韵（首句可借邻韵，谓之「孤雁出群」，
  须向用户说明是变例）。
- **填词以词林正韵 19 部为绳**：每部合数个平水韵部，上去通押；入声独立作五部。
- 判音依《广韵》：一字多读（「两」）者两可，广韵未收者如实报「无考」，不妄归。

## 工具用法
1. 单字归部：`char_rhyme(字)` → 声调大类 + 平水候选各部 + 词林归属。
2. 韵部全貌：`rhyme_group(部名)` → 该部字表（按语料常用度排序，前者常用）+ 词林归属；
   `rhyme_group()` 列 106 部总目，`tone` 参数可筛平/上/去/入。
3. 检一组韵脚是否同押：逐字 `char_rhyme` 取平水集合求交；诗须平水有交，
   词则词林有交即可。校验工具（check_jinti / check_ci）已内置此逻辑。
4. 某韵部历代作品：`works_by_tag("yun", 部名)` —— 看古人在此韵部下的实作（主韵部
   为每篇韵脚归部之众数），可再按朝代筛。

## 选韵建议法
- 宽韵（东支先阳庚尤真）字多易措，长律尤宜；窄韵险韵（江佳肴咸删）见巧亦见窘。
- 声情相配之说可供参考（东钟洪亮、支微幽细、萧肴清远、寒删苍凉），
  但如实告知此为词章家经验谈，非硬则。
- 想看「某韵部谁用得多、何代所尚」：作者层面用 `author_fingerprint(名)` 之 yun 字段，
  时代层面用 works_by_tag 按朝代抽看。

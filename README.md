# 墨一 · Mo Yi

**一墨藏万象** —— 基于 [CNPoetry-Hermes（诗海赫尔墨斯）](https://github.com/psknlr/CNPoetry-Hermes)
规则挖掘流水线的 **离线中华古典诗词档案馆 Android App**。

| | |
|---|---|
| 应用名 | 墨一（Mo Yi） |
| 包名 | `com.impfai.moyi` |
| 馆藏 | 130,720 首诗词 · 3,772 篇辞赋 · 222 篇古文 · 50 个意象档案 · 487 位诗人档案 · 578 个词牌 · 9 品题材 |
| 权限 | 仅 `INTERNET`（供兜底环回服务器使用）—— App 不发起任何对外网络请求，全部数据离线内置 |
| 加载架构 | 主路径 `file:///android_asset` 直载（不经网络栈，免疫缓存/代理/VPN 干扰）；异常时自动切换进程内环回 HTTP 服务器兜底 |
| 最低系统 | Android 8.0（API 26） |

## 设计语言

宣纸 × 松烟墨 × 朱砂印。界面以宣纸暖底、松烟墨字、朱砂印章为骨，
文武线、卷号（卷一/卷二）、竖排印章等传统书籍装帧元素贯穿全 App；
内置霞鹜文楷（OFL 许可）按 unicode-range 懒加载；深浅双主题随系统切换。

## 功能

- **今日一诗** —— 按日期从馆藏轮换，展卷即读。
- **意象** —— 两层：**档案意象 50 个**（字形封面、异形词、情感光谱、常见并置、朝代分布，
  **例证长卷**列出全部例证诗句并可逐条回源高亮）+ **广谱标注 203 个**（按天文/时令/地理/
  植物/动物/器物/建筑/人事/边塞/时空/人文十余门类编次，**全库统一表面标注，
  覆盖 97.0% 作品**，明清补遗等未参与规则挖掘者亦得标签）。
- **风格指纹** —— 1,114 位诗人的多维计量（惯用意象 / 体裁偏好 / 用韵倾向 / 平均篇幅 /
  **用韵偏离度**），**可择二家对读**：意象偏好按每首均次作差（消弭存诗多寡影响），
  另列共好意象与同用韵部。偏离度以余弦距离量其用韵与「**同代同体**」侪辈之别
  （词多仄韵、诗多平韵，混作一谈量的是体裁而非风格），样本不足或同组少于三家者不判。
  实测李贺 0.694 最独异（好用险韵，与文学史定论相合），李白 0.040 最从众。
- **韵部流变** —— 朝代 × 平水韵部的用韵占比热力，看某韵在历代此消彼长。
- **共现流变** —— 意象搭配的时代兴替：以**共现率**（二象同篇之数 ÷ 该朝作品数）
  比较六朝，附渐兴/渐微榜与逐对详情。实测「帘·柳」「梦·花」峰在五代（花间词之性）、
  「梅·花」峰在宋（宋人咏梅之盛）、「剑·酒」「剑·山」渐兴于明清。
- **六维雷达** —— 指纹页与二家对读均附雷达图（篇幅／象密／象广／近体／自然／人事），
  六维按全体 1,114 家的**分位**归一（量纲各异，绝对值不可径比）；单家页另叠
  **同代同体侪辈之均值轮廓**（灰虚线）以相形见其偏正。
- **用象之奇** —— 其惯用意象搭配在同代同体侪辈中的平均罕见度，以**组内分位**为准。
  为何不作「首创榜」：语料所见最早者几乎尽落唐代（唐前存诗甚少），那种榜单只是
  「作品多」的同义反复，更不能说「云·山」这等亘古常配为某家首创；此量不依年代先后，
  故不受语料抽样与朝代粒度之限。各组之首为李白（唐诗）、张可久（元曲）、苏轼（宋词）。
- **意象四时** —— 意象与季节的关联：季节**只由直接季节词判定**（「秋风」「暮春」，
  兼含两季者不判），所示为「诗人明言某季时同篇并用何象」，**不以物候反推季节**
  （那将是循环论证）。实测春之象为杏、莺、蝶、寒食、杜鹃，秋之象为雁、砧、菊。
- **星图/矩阵双层** —— 意象星图与情象矩阵均可在**档案层**（50，经审核）与
  **广谱层**（全库表面标注，80 节点 400 边）间切换。
- **文库** —— **分层书架**（12 朝代按时序 → 22 集部 → 子目，跨代过渡期如「元末明初」
  插于两朝之间并另作样式，不与主朝代平级）：集部行按其朝代限定进入，集部页可按作者筛选，
  元曲另按剧目/散套细分（585 目）；全文/题目/作者三模式即时检索（简繁通检），
  命中处出摘要，检索history留痕。
- **高级检索** —— 多条件组合：关键词（检索域 + 句位限定：任意/句首/句脚）、排除字、
  朝代、集部、体裁、意象、题材、句数区间、每句字数（齐言）；结果附朝代与集部分布统计。
- **文苑** —— 《古文观止》222 篇（含《阿房宫赋》《秋声赋》《前后赤壁赋》四篇辞赋
  与明文 12 篇），按时代/文体筛选，竖排可读；散文不入格律计量层。
- **对课** —— 《声律启蒙》（清·车万育）三十平韵属对，与韵表同一韵部口径。
- **情象矩阵** —— 情感 × 意象同篇共现热力表：**点格进交叉作品，点行首情感、点表头意象各自成集**。
- **交叉检索 · 全站数值可溯源** —— 意象 × 意象 × 情感 × 题材 × 语词 × 韵部 × 季节 ×
  朝代 × 集部 × 体裁 × 作者，十一维任意组合求交（倒排索引，秒出）。
  **全站每一个数字都可点开见其作品**：韵变表逐格（先秦 × 支韵 → 24 首含《关雎》）、
  意象朝代柱、共现搭配（剑·酒 → 668 首兼含二象者）、四时各条、指纹各条、
  统计 chip 逐层收束（杜鹃 → 明清补遗 1042 首）；条件可逐条摘除。
- **名句谱** —— 556 条**跨代化用实证**名句：不作主观选录，以「被两个以上朝代的作品重现」
  为客观闸门（元杂剧科介宾白虽集内高频却不跨代，由此自然滤除），可看最早出处与历代重现。
- **典故** —— 28 则种子（出处 / 寓意 / **歧义辨析**），语料表面命中作候选，标明「同一字面未必用典」。
- **对读** —— 任意两篇并置双栏比对，共用字朱砂标出，另计共有意象、情感、篇幅与体裁。
- **诗人档案** —— 小传（集内旁证 C 层）、惯用意象、体裁分布、存世作品全列表。
- **词牌定格** —— 语料归纳句式与一致率（B 层计量，不冒称词谱权威），例词全量可读。
- **题材九品** —— 定义、标志语汇、常见意象、归品作品。
- **格律** —— 阅读器一键全篇平仄注音（○平 ●仄 ⊙两读，依《广韵》逐字判定，
  多音不作语境消歧）；格律卡展示体裁计量、句式与韵脚归部；韵脚字青色标示。
- **点字释义** —— 诗中任意字一点即查：广韵读音（韵目/声调/反切）+
  《说文解字》训诂（部首/拼音/释义）。
- **创作实验室** —— 四页签：**诗谱**（五/七言绝句律诗 × 四起式标准谱，○●△符号谱）、
  **词谱**（龙榆生《唐宋词格律》153 调，定格变格符号谱、异名与调说，与语料定格互链）、
  **韵表**（平水韵 106 部按四声分组、常用字按语料频次排序；词林正韵 19 部；查一字即知归部）、
  **校验**（两种模式：*近体诗* —— 草稿逐句比对四起式，标出违律字位，检**粘对**（联内相反、
  联间相同）、**拗救**（孤平救 / 特拗四拗三救 / 半拗对句救，识出即不作出律论）、
  三平尾/三仄尾、韵脚归部一致性、与古人撞句并可回源对照；*依词谱填词* —— 点选词牌后逐字
  对谱位校验，**点谱位可查该位宜用之字**（韵位依已押韵部给同韵常用字），并核韵位归部）。
- **韵部聚类** —— 53 组语料实押韵伴；查一字知其韵伴，组内支撑作品全量可读。
- **互文关联** —— 8,180 篇的共享语段网络（化用/同源待考），阅读器内点击对照回源。
- **意象星图** —— 50 意象同篇共现网络（canvas 力导向布局），支持拖曳平移与
  双指缩放，点选星点高亮邻接、查看共现计量并一键跳转意象档案。
- **收藏夹** —— 阅读器一键「藏」，私藏诗笺存于本机（localStorage）。
- **飞花令** —— 以字为令；用户出句逐字校验「语料实有」，墨一应令句句可回源。
- **阅读器** —— 宣纸双框卡片、竖排切换、注释/赏析折叠、篇中意象一键跳转意象档案。

一切结论遵循流水线的证据法则：**无原文，不成论断；无篇目，不成证据** ——
App 内每一条意象-情感联系、每一条例证、每一句飞花令应对，点击即达原诗。

## 目录结构

```
moyi/                     Android 工程（Kotlin + WebView + WebViewAssetLoader）
  app/src/main/assets/www/    前端（零依赖 SPA）+ 数据 + 字体
agent/                    墨一·砚友：诗词语料智能体（17 件工具 + 5 门技艺 + MCP 服务器）
tools/export_app_data.py  从 CNPoetry-Hermes 流水线产物导出 App 静态数据
CNPoetry-Hermes-main (5).zip  原始流水线代码与语料
```

## 墨一·砚友（智能体版本）

`agent/` 是本馆的智能体形态：语料检索、韵书、龙谱、近体/依谱校验、意象档案等
做成 17 件可调用工具，跑在 Anthropic 工具执行器（Claude Opus 5）上，并以 5 门
「技艺」（领域工作流程）按需渐进披露；`--provider` 亦可换 OpenRouter / Poe /
MiniMax 等 OpenAI 兼容端点。同一套工具另以 MCP 服务器（stdio）暴露，
可直接接入 Claude Code / Claude Desktop。数据与 App 同源同口径，只读离线。

```bash
pip install -r agent/requirements.txt && export ANTHROPIC_API_KEY=...
cd agent && python -m moyi_agent            # 对话；python -m moyi_agent.mcp_server 起 MCP
```

详见 [agent/README.md](agent/README.md)。

## 构建

```bash
# 1.（可选）重新生成数据：解压 zip 后运行流水线，再导出
python3 -m hermes_poetry pipeline          # 在 CNPoetry-Hermes 根目录
python3 tools/export_app_data.py --hermes <CNPoetry-Hermes 根目录> \
    --out moyi/app/src/main/assets/www/data

# 2. 构建 APK（或直接用 Android Studio 打开 moyi/）
cd moyi && ./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

### Release 签名

`moyi/keystore.properties` 与 `*.jks` 均被 gitignore，不入库。首次签名：

```bash
cd moyi
keytool -genkeypair -keystore moyi-release.jks -alias moyi \
    -keyalg RSA -keysize 2048 -validity 10000
cat > keystore.properties <<'EOF'
storeFile=moyi-release.jks
storePassword=<你的密码>
keyAlias=moyi
keyPassword=<你的密码>
EOF
./gradlew assembleRelease   # 产物已签名：app/build/outputs/apk/release/app-release.apk
```

密钥库请妥善备份 —— 后续版本更新必须用同一把钥匙签名。

前端可脱离 Android 环境直接预览：

```bash
cd moyi/app/src/main/assets/www && python3 -m http.server 8765
# 打开 http://127.0.0.1:8765/index.html
```

## 语料分层与证据级别

| 层 | 规模 | 来源 | 证据级别 |
|---|---|---|---|
| 核心库 | 26,720 首 | chinese-poetry 开源整理本 | 参与全部规则挖掘 |
| 明清补遗 | 104,000 首 | [Werneror/Poetry](https://github.com/Werneror/Poetry) | **网络汇编（无底本/卷次/页码），非《全明诗》《全清诗》权威底本**；按作者分层抽样覆盖 13,659 位作者；仅供阅读、检索与格律计量，不参与意象与情感规则挖掘 |
| 辞赋 | 3,772 篇 | 《御定历代赋汇》清·陈元龙编，文渊阁四库全书本（[Kanripo KR4h0139](https://github.com/kanripo/KR4h0139)） | 原典 1706 年成书，正文公有领域；随篇保留卷次与四库页码，可回底本核校 |
| 文苑 / 对课 | 222 篇 / 30 韵 | 《古文观止》《声律启蒙》 | 原文直录 |
| 音韵训诂 | 21,940 / 11,179 键 | 《广韵》（韵典网整理本）、《说文解字》 | B 层计量 / C 层旁证 |
| 词谱 | 153 调 | 龙榆生《唐宋词格律》（longyusheng.org 整理本） | 词谱权威层 |

明清补遗按 `tools/build_mingqing.py` 生成：去重 → 过滤异常 → 按作者轮转分层抽样
（保证作者覆盖广度而非集中于高产者）。学界估计遗存清诗达数百万首，本层规模不足其零头，
**不得据此宣称「全明诗」「全清诗」**；正式研究请回权威底本核校。
